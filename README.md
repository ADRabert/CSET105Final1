# CSET 105 Final Project 1: Grocery List Manager

## Project Info
This first half of the final project for CSET 105 involves recreating the grocery list manager from previous lectures as an interactive webpage.

## Features
- Input field to enter the grocery to add
- Button which adds specified grocery to the list
- Options to view all items, only unpurchased items, or only purchased items
- Clicking on an unpurchased item marks it as purchased, and vice versa (uses strikethrough property)

For the second part of the final project, see [Final Project 2](https://github.com/ADRabert/CSET105Final2).
